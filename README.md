# ChatGPT 账号入口

一个轻量的 Chrome 扩展。点击「打开 ChatGPT」可继续使用当前账号；想临时使用另一个账号，点击「在无痕窗口登录」，在 ChatGPT 官网完成登录即可。

## 安装

1. 下载并解压[项目源码](https://github.com/0xErnest/chatgpt-account-launcher/archive/refs/heads/main.zip)。
2. 打开 `chrome://extensions/`，启用「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
4. 在 Chrome 工具栏的扩展菜单中打开「ChatGPT 账号入口」。

同一 Chrome 个人资料下的无痕窗口共享登录状态。要长期保留多个独立账号，可为每个账号使用单独的 Chrome 个人资料。
